> **状态**：现行产品定义（2026-09）  
> **ADR**：[0009](../decisions/0009-earthwork-minecraft-tool-not-civil-cad.md)

本文件是土方插件的**产品准绳**。领域模型与管线文档描述「底层可以有什么」；本文件决定「玩家看见什么、近期做什么」。两者冲突时，**以本文件为准**。

---

## 一句话

让任何 Minecraft 玩家在几十秒内把复杂地形变成适合建造的场地，并在这个过程中直观理解什么是挖方、填方、平衡标高和边坡。

## 是 / 不是

| 是 | 不是 |
|----|------|
| 建造玩家的智能地形整形工具 | Minecraft 里的 Civil 3D / InfraWorks |
| 用可视化讲清挖填、平衡、边坡 | 工程造价土方系统 |
| Plot 里道路 / 建筑 / 地形的衔接层 | 岩土施工仿真 |

玩家真正要走的主流程：

```
地形高低不平
  → 框选建房 / 城堡 / 广场的区域
  → 插件告诉：这里挖多少、那里填多少
  → 推荐一个比较合理的高度
  → 看预览
  → 微调
  → 一键施工
```

**绝不能**把下面这些做成主流程（学习扩展可以藏在 Learn Mode）：

土壤分类、松方/压实系数、跨场地运输矩阵、施工工作面、岩土适用性、项目级调运优化。

## 产品原则

1. **学习工具要把复杂变简单**，不是把专业软件搬进 Minecraft。
2. **底层可以保留复杂架构，玩家 UI 大约只暴露 20%。**
3. **现在开始收敛产品，不再增加领域对象。** 现有 Site / Zone / Pad / Pit / Corridor / Landscape / Exclusion / Breakline / Retaining / 多层 Balance / Conversion 已接近 Minecraft Mod 复杂度上限。
4. **默认按玩家直觉：挖 1 块 ≈ 填 1 块。** 可利用率、压实换算只在学习模式出现，并且先给结果再给「为什么」。
5. **Minecraft 高度是整数。** 平衡与推荐用离散扫描（含边坡后的最终方量），不要连续优化器。
6. **指标用 blocks 和「工作量」说话。** `geometricCutVolume` 可以留在代码里，不要出现在主 UI。

---

## 玩家真正需要的 6 件事

1. **平整场地**（绝对第一核心）：框选 → 看现状高度 → 推荐整平高度 → 挖/填/差值/平衡度。
2. **交互式目标高度**：slider 改 Y，CUT/FILL 与预览实时变。
3. **Cut / Fill 3D 可视化**：红挖、蓝填、绿不动（或透明 voxel）+ 方块计数与平衡度。
4. **自然边坡**（Minecraft 地形美化）：垂直 / 自然坡 / 缓坡 / 挡墙；高级再展开 1:1、1:2、1:3。
5. **建筑平台**：轮廓 → 平整区 + 周边坡。UI 叫「平台高度」，不要 ±0.000 / 施工控制标高。
6. **地下开挖（Minecraft 化）**：平台高度 + 「往下挖 N blocks」→ 坑底。不要底板厚度、工作面。

道路走廊联动、排除区、挡土墙、多 Zone 是建造增强，不是专业软件功能过度；但它们排在平整与可视化之后。

## 三种工作模式

| 模式 | 给谁 | 界面里有什么 |
|------|------|----------------|
| **Quick** | 绝大多数玩家 | 选区域；目标 = 自动平衡 / 指定高度；边缘 = 自然 / 垂直 / 挡墙；预览 |
| **Builder** | 高级建造玩家 | 建筑平台、道路衔接、地下开挖、多区域、排除区、局部高度、边坡强弱、材料 |
| **Learn** | 想看原理的人 | CUT/FILL、净土方、平衡高度、剖面、挖填曲线、材料利用率；每个指标可点「为什么？」 |

默认 **Quick**。专业字段不得出现在 Quick。

### 默认：Minecraft Mode

- Reusable Ratio = 100%
- Conversion Ratio = 100%
- 挖出的土方块可以直接拿去回填

Learn Mode 再解释：现实里挖出的土通常不能 100% 回填，并展示可利用率 / 压实换算。讲解顺序必须是：

1. 挖出 500，需要回填 430；其中 430 可回填，剩余约 70  
2. 点「为什么？」才出现松散、压实、不可利用土

不要先甩 `Reusable Ratio = 0.9`。

## 核心体验（必须强化）

### 交互式平衡

目标高度列表旁实时显示该 Y 的挖、填、余缺。拖 slider，地形预览跟着变。这比继续做 `ZoneAllocationBalanceAdjuster` 更重要。

### 两个「最佳高度」（不要合成一个黑盒）

| 方案 | 目标 | 玩家学到的事 |
|------|------|----------------|
| ⚖ 挖填平衡 | 最小化 `|Cut − Fill|` | 尽量不从外面运土 |
| ⛏ 最少施工 | 最小化 `Cut + Fill` | 平衡 ≠ 最少干活 |
| 🏗 当前建筑高度 | 玩家锁死的平台 Y | 为了贴建筑愿意多挖/多填 |

以后可加 **保持自然地形**（少削山、少填谷、少动边界）。这是 Minecraft 特有目标，不是专业软件搬过来的。

### 平衡曲线（学习特色）

横轴标高、纵轴土方量：挖方随 Y 升高而增加、填方减少；标出挖填平衡点与总工作量最低点。

### 工作量（Minecraft 指标）

主 UI：挖掘 N blocks、回填 M blocks、预计改变 N+M。可再给「改造规模」条和「手工施工难度」星级。内部仍可用 `geometricCutVolume`。

已有的几何方量 vs 实际改方块（空气列等）要保留并展示为：

- 土方计算：挖 / 填  
- 实际世界修改：移除 / 放置

### 推荐原因（一句话能看懂）

> 推荐 Y69，因为挖 342 / 填 351，差值仅 9。比 Y68 少搬运 207，比 Y70 少搬运 184。

### 五种教育可视化（P2，不是继续堆求解器）

1. 剖面：现状 vs 设计，标注 CUT / FILL  
2. 挖填热力图  
3. 标高—方量曲线  
4. Before / After  
5. 为什么推荐这个高度

## 保留但改口吻的能力

| 能力 | 做法 |
|------|------|
| 边坡 | 保留 `ZoneBoundarySlopeApplicator`。Quick：垂直 / 自然 / 缓坡 / 挡墙 |
| Building Pad | 保留。默认不允许自动改高度 |
| Excavation Pit | 保留。「地下开挖深度：N blocks」 |
| 挡土墙 | 保留。可用石砖 / 圆石 / 深板岩砖 |
| Road Corridor | 保留并作为 Plot 特色：道路 ↔ 地形 ↔ 建筑共用一套场地 |
| 多 Zone / 排除区 | Builder 暴露 |
| Zone Allocation | **不要**自动改各 Zone 标高；改成「土可以去哪」的流向示意 |
| MaterialConversionModel | 底层保留，默认隐藏 |
| Cross-site / Project Global | 底层可留，普通模式隐藏，标成 Advanced / 实验 |

### 高度约束（替代 LOCKED / DERIVED / BOUNDED）

每个区域只要：

- `autoAdjustElevation`（允许自动平衡调整）  
- `maxAutoAdjustment`（例如 ±3 blocks）

建议默认：平整/景观 = 允许；建筑平台 / 道路 = 不允许。不要做完整工程约束体系。

## 明确冻结（直到产品主动解冻）

- 专业材料工程模型、土质兼容性、结构填土/种植土/岩石分类  
- 跨场地施工物流、运输路径、机械调度  
- 成本模型、专业项目级报表作为主流程  
- Newton / 连续梯度 / 复杂约束优化器  
- 基坑底板厚度、施工工作面、复杂基坑工程模型  
- VerticalAdjustmentPolicy 的 LOCKED/DERIVED/BOUNDED 全家桶  

冻结不等于删代码；等于**不再作为近期开发重点，不得进入 Quick/Builder 主路径**。

## 近期路线（按优先级，不是按领域完整度）

### P0 — 算得对

1. **自动平衡必须用最终边坡之后的实际方量。** Minecraft 做法：对候选整数 Y，完整生成含边坡的设计地形再算 Cut/Fill，取 `|cut − fill|` 最小者。不要先平衡再放坡还显示 Balanced。  
2. **建筑/道路固定高度不能被偷偷改掉。**  
3. **Preview / Build / Report 三者数字与方块必须一致。**

不需要复杂工程迭代 Solver。候选区间即使 Y55–Y90 也只有几十次完整生成。

### P1 — 玩家好用

Quick Mode、目标高度 slider、实时 CUT/FILL、一键推荐高度、自然坡、Ghost Preview。

### P2 — 玩家看得懂

Cut/Fill 颜色、剖面、高度—方量曲线、Before/After、推荐原因；几何量 vs 改方块；工作量。

### P3 — 建造联动

Building Pad、Road ↔ Terrain、地下空间、挡墙、多 Zone（Minecraft 文案与默认值）。

### P4 — Learning Mode

把已有 MaterialConversion、Allocation Matrix、Project Balance **包装成教学内容**，而不是继续加深模型。

## 目标体验（验收时对照）

```
玩家：我想在这里建城堡。

Plot：
  平台 Y72：挖 1,240，填 340
  降到 Y69：挖 690，填 655（更接近平衡）
  [预览 Y72]  [预览 Y69]
  边缘：自然坡
  预计修改：1,416 blocks
  [开始施工]
```

这既不是 WorldEdit 一键平地，也不是 Civil 3D。
