# 道路编辑面板专业工具检查

范围：标准横断面、可变横断面、平面线形、沿线设施、诊断、批量横断面六个工具，以及共享浮动窗口与编辑会话。

## 已修复

- 比较工程数据内容，避免快照中的对象副本被误判为修改；材质组合按内容比较。
- 标准横断面保存保留继承参数，恢复继承也能被识别为编辑。
- 可变横断面和沿线设施在恢复、重开及工作副本替换后刷新表单。
- 无效桩号、重复断面、设施区间和挡土墙高度阻止保存，避免静默丢弃已有条目；关闭时提示未保存编辑。
- 短道路的默认桩号和滑块范围不再出现上下界倒置。
- 保留未编辑的双精度桩号与设施高度。移动断面桩号时保留原模板的继承参数和表单未暴露的材质字段。
- 批量横断面绑定打开时的道路集合，避免选集变化后修改其他道路；恢复同时重置独立表单草稿，保留撤销能力。
- 无修改的窗口可随网络版本刷新，也可正常关闭；已有修改继续执行版本冲突保护。
- 诊断使用对应的实时网络；工作副本诊断不复用实时网络的版本缓存。
- 工具入口在窄面板中使用单列布局。

## 回归覆盖

`ProfessionalToolRegressionTest` 与 `ProfessionalToolDraftRegressionTest` 覆盖无操作保存、参数继承、表单恢复、无效输入、批量作用域与撤销、诊断缓存、短道路及数值精度。

同时运行道路 UI、线形、桩号、平面中心线、诊断、断面模型、设施模型、道路管理器与批量编辑相关测试：278 项通过，0 项失败。`assemble` 构建成功，产物为 `build/libs/plot-1.0.0.jar`。
