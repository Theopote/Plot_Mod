# 扩展插件

Plot 内置多个插件，通过右侧栏的 **扩展** 标签页访问。

## 打开扩展面板

1. 在 Plot 界面右侧切换到 **扩展** 标签
2. 在顶部图标栏中点击要使用的插件（再次点击可取消选中）
3. 勾选 **启用插件** 后，下方会显示该插件的参数与操作界面

> 插件默认可能未启用，需手动勾选后才能使用。

## 已安装插件

| 插件 | 说明 |
|------|------|
| **土方平衡** | 把高低不平的地形整成可建造场地，并看清挖多少、填多少 |
| **道路系统** | 沿路径规划与生成道路结构 |
| **建筑轮廓生成器** | 从多边形或矩形轮廓生成建筑 |
| **图案生成器** | 认领闭合铺装区域，用程序化图案或导入图片像素画替换地表方块 |
| **电力线路** | 沿直线/折线走线布置电线杆，生成带垂度的装饰性导线 |

土方平衡、道路系统、建筑轮廓生成器、图案生成器采用 **概览 / 认领 / 编辑 / 生成** 四个标签页；电力线路采用 **线路 / 样式 / 建造**（线路 Tab 内含线路列表与总览图）。

## 道路系统

### 典型流程

1. 在画布上用折线、样条等工具绘制道路中心线
2. 打开 **扩展** → 选择 **道路系统** → 启用插件
3. 在 **认领** 标签页沿路径认领道路
4. 在 **编辑** 标签页设置路宽、横断面、材质与节点标高
5. 在 **生成** 标签页预览幽灵方块，确认后投影到世界

### 主要能力

- 道路预设（城市主干道、次干道、乡村公路、高速公路等）
- 路宽、材质、坡度与桥梁/隧道阈值
- 人行道、路肩、排水沟、路灯等附属结构
- 路口标线（自动/强制开启/强制关闭）
- 挖填方估算与预览建造

### 属性面板联动

选中道路节点时，右侧 **属性** 标签页会额外显示 **道路节点属性**，可直接编辑节点标高。

### 配置文件

- 全局配置：`.minecraft/config/plugins/road_system.json`
- 项目数据：`.minecraft/plot/plugins/road_system/networks/`

## 土方平衡

面向建造玩家：框选要建房/城堡/广场的区域，插件推荐比较合理的整平高度，用红色/蓝色虚影标出挖和填，确认后一键施工。默认按「挖 1 块 ≈ 填 1 块」计算，不要求理解压实系数或跨场地调运。

### 典型流程

1. 绘制或选择封闭区域作为整平范围
2. 打开 **扩展** → **土方平衡** → 启用插件
3. 在 **认领** 标签页拾取/认领区域
4. 查看推荐高度与挖填方块数，需要时拖动目标高度并看预览
5. 选择边缘（垂直 / 自然坡 / 挡墙），确认后建造

### 整平曲面模式

| 模式 | 说明 |
|------|------|
| 水平（FLAT） | 统一标高整平（最常用） |
| 定坡（FIXED_SLOPE） | 固定坡度 |
| 三点定面（THREE_POINT） | 由三个点确定平面 |
| 拟合斜面（FIT_SLOPE） | 根据区域数据拟合斜面 |

### 主要能力

- 推荐平衡高度与挖/填方块统计
- 幽灵方块预览（挖方红色、填方浅蓝色）
- 边缘自然坡或挡墙（避免垂直切坡过丑）
- 区域列表与插件内撤销/重做
- 可选：建筑平台、地下开挖、与道路衔接（建造向，不是工程造价）

### 数据保存

- 全局配置：`.minecraft/config/plugins/earthwork_balance.json`
- 项目数据：`.minecraft/plot/plugins/earthwork_balance/projects/`

## 建筑轮廓生成器

### 典型流程

1. 在画布上绘制建筑底面轮廓（矩形或多边形）
2. 打开 **扩展** → **建筑轮廓生成器** → 启用插件
3. 在 **认领** 标签页拾取/认领轮廓
4. 在 **编辑** 标签页配置楼层、高度、基础填充与屋顶
5. 在 **生成** 标签页生成 3D 预览并投影建造

### 主要能力

- 从 2D 轮廓生成 3D 建筑体块
- 多建筑项目管理
- 幽灵预览与实际方块放置

### 数据保存

- 项目数据：`.minecraft/plot/plugins/building/projects/`

---

## 图案生成器

在画布上认领闭合区域，用棋盘格、条纹、同心环、马赛克等程序化图案，或导入 PNG/JPG 像素画，替换地表一层方块（不整地形）。适合广场铺装、地面纹理、像素画地坪。

### 典型流程

1. 用多边形/矩形/圆形/椭圆工具绘制 **闭合** 铺装范围（折线需首尾重合）
2. 打开 **扩展** → **图案生成器** → 启用插件
3. 在 **认领** 标签页拾取/认领区域（同时选中外环与内环可自动识别孔洞）
4. 在 **编辑** 标签页选择程序化图案或 **导入图片**，配置材质/调色盘与 fit 模式；需要留空时可 **从选区添加孔洞**
5. 在 **生成** 标签页 **计算预览**（幽灵方块）→ **确认落地**

### 主要能力

- 四种程序化图案 + 图片像素画（拉伸 / 包含 / 平铺）
- 编辑页可从画布选区添加**孔洞**；认领时同时选中外环+内环可**自动识别孔洞**（画布橙色轮廓）
- Pattern Space 画布坐标采样，与世界投影分离
- 幽灵预览（独立 owner，不干扰其他插件）
- 落地撤销/重做（仅恢复实际成功的格子）
- 图片模式分条诊断（未导入 / 文件丢失 / 全透明 / 调色盘空）
- 区块未加载时预览会提示 Y=64 回退格数，过多时拒绝落地

### 数据保存

- 项目数据：`.minecraft/plot/plugins/pattern/projects/`
- 导入图片：`.minecraft/plot/plugins/pattern/images/`

## 电力线路

沿画布上的直线或折线走线，自动布置电线杆与横担，生成带垂度的装饰性导线（铁栏、锁链、避雷针等材质）。适合街区配电、郊区路灯、高压格构塔等场景。

### 典型流程

1. 在画布上用直线或折线工具绘制走线路径
2. 打开 **扩展** → **电力线路** → 启用插件
3. 在 **线路** 标签页点击 **拾取路径**，点选或框选路径后右键完成，再 **认领线路**
4. 在同页设置杆塔间距、高度、地形避让等；展开底部 **全部线路** 可查看总览图并切换选中线路
5. 在 **样式** 标签页选择风格预设（木杆、混凝土、格构塔等），可用 Quick Customize 微调杆材与垂度
6. 在 **建造** 标签页点击 **计算预览** 查看幽灵方块，确认后 **预览并落地**

### 主要能力

- 25+ 风格预设（木杆、日式街区、混凝土、格构塔、蒸汽朋克等）
- 按最大间距自动插杆，转角处强制立杆
- 单相 / 三相导线、垂度比例与材质
- 地形净空检查与自动修正走线
- 线路检查（间距、垂度、导线重叠等）与画布叠加层
- 杆塔设计器（自定义杆型）
- 插件内撤销/重做（线路编辑）与世界建造撤销

### 数据保存

- 项目数据：`.minecraft/config/plugins/power_line/projects/`
- 杆塔设计：`.minecraft/config/plugins/power_line/pole-designs/`

## 插件通用说明

### 拾取模式

土方/建筑/道路/图案/电力线路的认领或拾取操作会临时接管画布点击。完成拾取前请勿切换到其他工具；按 **Esc** 可取消拾取。留意状态栏提示。

### 与绘图工具的冲突

插件拾取模式、图库放置模式一样，在特殊模式下会优先捕获画布输入，绘图工具不会响应。

### 插件数据 vs 画布项目

各插件会在 `.minecraft/plot/plugins/` 下保存自己的项目数据（JSON）。插件配置保存在 `config/plugins/` 目录。

这与画布主设计的「项目文件」不同。画布图层会自动保存到 `.minecraft/plot/projects/default.json`；插件配置保存在 `config/plugins/`，插件项目数据保存在 `plot/plugins/`。

## 常见问题

### 扩展面板是空的或按钮无反应

确认已在插件名称旁勾选 **启用插件**，且已点击顶部插件图标选中该插件。

### 拾取区域时没有响应

拾取模式会临时接管画布点击。完成拾取前，请勿切换到其他工具；按 **Esc** 可取消拾取。

### 与绘图工具冲突

土方/建筑的区域拾取、图库放置、道路路径认领、图案区域认领、电力线路路径拾取，在特殊模式下会优先捕获画布输入。留意状态栏提示。
