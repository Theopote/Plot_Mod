# ADR 0011：土方插件按地形任务收敛入口

## Status

Accepted — 2026-10-26。承接 ADR 0009，本轮由用户明确要求精简 Minecraft 地形修改中低价值的功能。

## Decision

1. Builder 合并「区域类型」和「曲面模式」两套分类，提供六个任务：平整、斜坡、顺应地形、建筑平台、挖坑、道路衔接。斜坡保留坡向与三点两种方法；顺应地形保留现状偏移和拟合两种方法。
2. 不再创建独立排水曲面或多平面。旧排水模式沿用既有拟合面兼容映射；旧多平面的子面继续读取和生成。查看任务或打开面板不替换旧设计。
3. 删除区域和全场的挡墙手动同步按钮。边界挡墙由生成管线自动派生；独立墙体和旧持久化墙体继续兼容。
4. 删除难度星级、区域页的跨场地平衡汇总、生成页的全局工程报告。保留当前场地和区域挖填明细、实际方块修改数量、图表与预览导出。
5. 推荐方式只提供「各区域分别推荐」和「整体调整场地」。旧 PROJECT / 约束分区优化策略保留读取、执行和保存，界面明确标为原方案；只有玩家主动选择新方式时才替换。
6. 建筑关联的基坑只编辑合计开挖深度与向外扩展，不再分别编辑楼面深度、基础厚度和施工超挖；未关联建筑的坑底仍可指定绝对 Y。底层三字段保留兼容，合计深度最大 192 格，避免旧深坑被截断。
7. 材料换算、共享领域模型和旧管线不是本次整包删除对象。它们有旧数据、导出、测试或其他插件依赖；本轮先删除玩家入口及只服务于这些入口的 UI 代码。

## Compatibility and validation

- 任务推导和策略识别不得修改序列化后的设计。
- 平台、基坑、道路、贴合地形和旧景观类型在保存时不得被兼容曲面枚举覆盖。
- 新任务切换会主动移除旧烘焙标高，防止旧缓存遮蔽新任务；这属于可撤销的显式编辑。
- 验证任务切换、旧多平面与策略往返、深坑合计深度、土方管线和道路联动。
