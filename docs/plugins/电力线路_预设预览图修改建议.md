# 电力线路 · 风格预设预览图修改建议

> **日期**：2026-09-07  
> **现象**：Style 画廊里有些卡片「看起来不像」对应风格（格构塔像实心灰块、风电不像风车、日式/路灯/钢杆彼此太像）。  
> **范围**：卡片缩略图（`PowerLineStyleCardRenderer.drawPackPreview`）、体素立面（`PoleVoxelizer` / `PoleVoxelElevationRenderer`）、预设绑定（`PowerLineStylePreviewBinding`）。  
> **不改**：`apply()` 落地几何本身；问题在 **预览怎么画**，不是预设没套上。

自动化测试 `PowerLineStyleConsistencyTest.previewBindingAlignsWithApply` 只断言「卡片用的设计 ID 和 apply 一致」。ID 对了，缩略图仍可以不像。

---

## 预览现在怎么画

```
Style 卡片 120×144（立面区约 116×92）
  → PowerLineStylePreviewBinding.previewDesign(preset)
  → PoleVoxelizer.voxelize(design)
       ├ 有塔体结构：腿 + 斜撑 + 横担（无绝缘子、无导线、无装饰）
       └ 分层杆：COLUMN / CROSSARM / CAP（无挂点、无导线）
  → PoleVoxelElevationRenderer.drawFront  （卡片只有正视）
       每个 (x,y) 取该列所有 z 里 z 最大的体素 → 整座塔「压扁」到一张图
       格子 < 0.8px 就 2×2 / 4×4 合并占用
```

悬停 tooltip 才有正视 + 侧视；画廊里玩家只看见正视小图。

---

## 不像的根因

### 1. 正视把整座塔的厚度压成实心剪影（格构塔最惨）

`PoleVoxelPreviewModel.blockAtFront(x, y)` 遍历所有 z，留下 **z 最大** 的那一格。四腿格构 + X 斜撑在很多 (x,y) 上都有体素，正视变成一块实心梯形。

测试已经写明：Monster Pylon 在卡片尺寸下是 `FILLED` LOD、格子 < 2px。斜撑细节全部糊掉。Classic / Heavy / Mega / Triple-arm / Cup 同一套算法，所以输电、工业这两组卡片会 **看起来都是一块铁灰色锥子**。

### 2. 卡片太小，高塔只能糊成色块

立面区约 92px 高。Monster 体素高度 ≥ 40，格子 ≈ 2px 或更小，再 downsample 更糊。玩家分不清「杯型塔 / 门型塔 / 三层横担 / 巨塔」。

### 3. 导线、绝缘子、装饰根本没画进缩略图

`PowerLineStylePreviewBinding.BindingKind.POLE_WITH_DECORATIVE_OVERLAY` 注释写「叠加装饰性导线/配件」，**渲染器没有实现**。`drawPackPreview` 只体素化杆/塔。

后果：

| 预设 | 玩家以为会看到 | 卡片实际 |
|------|----------------|----------|
| Classic / Rustic Wood | 木杆 + 导线下垂 | 一根细柱 + 一条横担 |
| Japanese Street | 密导线 + 灯笼 | 深色杆 + 双横担（灯笼是 1 格 CAP） |
| Suburban Lamp | 路灯头 | 铁杆 + 铁横担（`soul_lantern` 无调色） |
| Modern Utility | 变压器盒 | 铁杆中段一块铁块 |
| Wasteland Wind | 风车叶片 | 高柱 + 一条 9 格横担（像晾衣杆） |
| 所有三相预设 | 3 根导线 | 只有卡片下方文字「N 根线」 |

### 4. 特征方块没有预览色，横担/灯头变成乱色或灰

`BlockPreviewColors` 只收录了围栏、铁、石砖、铜、链、藤、荧石等。目录里实际用到、但 **没有调色** 的包括：

`oak_slab` / `dark_oak_slab` / `birch_slab` / `spruce_slab` / `mossy_cobblestone_slab` / `gold_block` / `cut_copper` / `oxidized_copper` / `orange_terracotta` / `sea_lantern` / `soul_lantern` / `cobweb` / `quartz_block` / `iron_trapdoor`

未收录的走 hash 随机灰绿。横担颜色对不上杆身，灯笼/金顶/蛛网这些「一眼能认」的帽子全糊掉。Suburban Lamp、Steampunk、Abandoned、HV Glass 尤其明显。

### 5. 很多钢/铁预设材质撞车

Simple Steel、Modern Utility、Compact Lattice、Suburban Lamp、多数格构塔，主材都是 `iron_bars` / `iron_block`（预览色几乎同一片灰白）。没有导线和灯头时，卡片只剩「细灰柱 vs 粗灰柱」。

### 6. Smart Towers 用了「小号格构」当代表

`StylePreviewKind.ADAPTIVE` → `LATTICE_SUSPENSION_SMALL_ID`（约 18 格高）。`apply()` 套的是分级塔族，生成时会换中/高塔。卡片看起来像 Compact Lattice，不像「智能换塔」。

### 7. 风电预设几何本身不是风车

`wastelandWindTurbine()`：12+4 柱 + 长度 9 的 CROSSARM + 活板门帽。世界里也是「高杆 + 一条横担」，卡片只是忠实地画出这个不像风车的模型。要「像」，预览（或设计）得加桨叶，不能只靠 CROSSARM。

## 分预设：谁最不像

按「卡片能否让玩家在画廊里认出来」粗分。

**还能认（小修即可）**

- Classic Wood、Double Wood、Urban Concrete、Old European、Rustic：木/水泥轮廓对，补 slab 颜色和一根示意导线即可。
- Fantasy Copper：铜块色已在表里。

**容易混（钢杆一组）**

- Simple Steel / Modern Utility / Compact Lattice / Suburban Lamp：全是铁杆。必须靠横担层数、灯头色、导线数量把轮廓拉开。

**糊成铁块（输电 + 工业）**

- Classic Lattice、Heavy Lattice、Compact 格构塔、Tapered、Triple Arm、Cup、Mega、Double Circuit、Portal、Monster、Smart Towers。  
  正视实心化 + 小格子是主因。Cup / Portal / Triple-arm 的辨识全在横担层，92px 里被塔身吃掉。

**几何就不是那个东西**

- Wasteland Wind：横担当叶片。
- Japanese Street：「密导线」只在文案里。
- Abandoned：蛛网 CAP 无颜色。

## 修改建议（按优先级）

### P0 — 先让格构塔不再是实心灰锥

**正视改成「前表面」而不是「穿透整座塔」。**

`blockAtFront` 只收 `z` 接近 `minZ` 的体素（例如 `z <= minZ + 1`），侧视同理用 `minX` 薄片。斜撑不再把塔腹填满，四腿和横担会分开。

卡片尺寸下若格子仍 < 1.2px：不要对占用做 2×2 并格（并格会更实）；改为：

1. **裁切**：只画塔身上半（横担区），或  
2. **统一缩放到「特征框」**：保证横担宽度至少占卡片 60% 宽度。

Monster / Mega 优先裁切上 50% 高度，让三层横担成为主体。

### P1 — 补上「风格暗示」层（注释里已经承诺）

在体素正视之上，用 ImGui 线再画一层，**不要**把导线体素化（会更糊）：

| 元素 | 画法 |
|------|------|
| 相线 | 从各挂点（`ConductorAttachment` lateral/vertical）拉水平短线，颜色用导线材质 |
| 顶线 | 更淡、更高的一条 |
| 绝缘子 | 挂点下方 2–4px 短竖线 |
| 导线数量 | 已有「N 根线」文案，保留 |

`BindingKind.POLE_WITH_DECORATIVE_OVERLAY` 真正落地。木杆、日式、三相塔会立刻「像电线」。

风电：预览层画 2–3 条过中心的斜线当桨叶，或给 `wastelandWindTurbine` 加两条斜 CROSSARM；只改预览更快。

### P1 — 补全 `BlockPreviewColors`

至少覆盖当前 catalog 用到的 slab / 灯 / 铜变体 / 金 / 海晶灯 / 灵魂灯笼 / 蛛网 / 活板门 / 石英。横担应和杆身同色系（oak_slab ≈ oak_fence）。

Suburban Lamp 的 `soul_lantern`、HV Glass 的 `sea_lantern`、Steampunk 的 `gold_block` 必须是固定色，不能 hash。

### P2 — 画廊卡片信息

1. **卡片上同时给正视 + 极窄侧视**（tooltip 已有，缩到卡片里）。门型塔、杯型塔侧视差很大。  
2. 或把卡片立面区加高到 ~128px（CARD_HEIGHT 提到 ~176），输电塔少糊一档。  
3. Smart Towers 不要用 Small Lattice：用 Medium，或三座并排小剪影表示「会换塔」。  
4. 钢杆组用轮廓区分，不要只靠铁灰色：Utility 短横担、Lamp 加暖色点、Compact Lattice 加两层横担强调。

### P2 — 测试不要只锁 ID

在现有 consistency 测试上加「视觉可分」：

- 体素包围盒宽高比（木杆瘦、门型塔宽、风电「一横」）。  
- 卡片尺寸下 `groupSize` 与「前表面」非空列数：格构塔前表面空列应 > 0（证明不是实心）。  
- `BlockPreviewColors` 对 catalog 出现过的 block id 必须有表项。  
- 断言 `previewDesign` 的 attachments 数量与卡片文案 `attachmentChannelCount` 一致，且 overlay 会画。

## 建议实施顺序

1. `blockAtFront` / `blockAtSide` 改为薄片正视（格构塔立刻不像铁块）。  
2. 补 `BlockPreviewColors`（木杆横担、灯头、金顶一次修好）。  
3. 卡片上画挂点导线 overlay（木杆/日式/三相认得出「是电线」）。  
4. 高塔裁切到横担区；Smart Towers 换代表设计。  
5. 风电预览加桨叶示意。  
6. 补视觉回归测试。

第 1–3 步不改世界生成，只改 UI 预览，风险低、观感差最大。

---

## 验收

玩家在 Style 画廊不点开 tooltip、不读名字，应能分出至少这些组：

- 木杆 / 水泥杆 / 铁杆 / 路灯  
- 格构塔（能看见空心或斜撑，不是实心锥）  
- 三层横担 vs 杯型 vs 门型  
- 风电（有叶片）vs 普通高杆  
- 铜/蒸汽朋克（暖色）vs 铁塔（冷灰）

通过标准与 `电力线路_风格一致性验收.md` 一致：**「这就是卡片上那种风格」**，而不是「点进去才知道是哪个」。
