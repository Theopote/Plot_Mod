# 电力线路 — 风格一致性验收

> **产品优先级**：好看 → 好操作 → Minecraft 常识 → 后台工程保护  
> 本清单用于验收「Style 卡片缩略图承诺的风格」与「实际生成结果」是否一致。

---

## 验收维度

| 维度 | 检查什么 | 自动化 |
|------|----------|--------|
| **缩略图** | Style 卡片 / Build 紧凑预览的杆塔轮廓、导线数量暗示 | 部分（`PowerLineStylePreviewBinding`） |
| **几何** | 生成杆塔高度、横担、塔体结构是否与 `PoleDesign` 一致 | 冒烟（有方块输出） |
| **材质** | 导线 / 地线方块 ID 与预设一致 | ✅ 每预设 wire material |
| **导线布局** | 单相 vs 三相、挂点横向/纵向分布 | ✅ conductor count |

**已知架构限制（验收时勿误判为 bug）：**

- 杆塔**实体方块**来自 `PoleDesign` 分层材质，**不是** footprint 上的 `poleMaterial`（后者用于预设匹配与默认杆 fallback）。
- 缩略图为 ImGui 矢量示意，**不会**与 Minecraft 像素级一致；装饰性导线/光晕/齿轮等叠加仅作风格暗示。
- 塔型族预设（Classic Lattice、Smart Towers）缩略图展示**代表塔型**，生成时按转角/角色解析不同设计。


覆盖：19 预设 `apply()` 往返、挂点数量、预览绑定、垂度、生成冒烟、中英 i18n 键。

## In-Game 验收流程（每条线路约 2 分钟）

1. **认领** 一条 40–80 格直线路径（平地）。
2. **Style** 选目标预设 → 确认卡片高亮、缩略图符合预期风格名。
3. **Build** → **计算预览** → 确认紧凑缩略图与 Style 卡片一致。
4. **环顾** 第一座杆塔：轮廓（木杆/水泥/格构/风车等）是否与缩略图同类。
5. **导线**：单相 1 根 / 三相 3 根；材质颜色（铁栏/铜/链等）是否符合预设。
6. **垂度**：松垂（Abandoned、Fantasy）vs 笔直（Modern Utility、HV Glass）是否肉眼可辨。
7. （可选）**落地建造** 一小段，步行贴近确认材质与比例。

**通过标准**：玩家无需读工程面板即可说「这就是卡片上那种风格」。
