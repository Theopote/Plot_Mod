# 电力线路插件 · 代码审查

> **日期**：2026-09-07（复审，对照上一轮 P1 修复后的代码）  
> **范围**：`com.plot.plugin.PowerLinePlugin`、`com.plot.plugin.powerline.*`、对应测试、i18n、用户向导  
> **结论**：上一轮列出的主路径断点（弹窗、预览改线、过期报告、隐形加杆）已经修好。当前 **没有 P0**。还剩文档缺口、叠加层边界、以及若干界面重复/死代码。

## 一句话

四 Tab 主路径现在是通的：认领 → 间距/风格 → 只读预览 → 确认建造；地形修正和智能优化走单独按钮并进撤销。剩下的问题不再挡住「能生成」，而是 **用户向导没写这个插件**、**画布叠加不看当前扩展**、以及建造页上的一些重复入口。

## 架构（当前）

```
PowerLinePlugin
  └ PowerLineUiContext / PowerLineActions
        概览 → 线路（认领）→ 样式（含杆塔设计器）→ 建造
        延迟弹窗：删除 / 建造 / 优化 / 设计器

生成：PowerLineGenerator
  布局 PowerPoleLayoutUtils（强制点 + maxSpacing + layoutConstraints）
  杆型 PoleDesignAssignmentResolver
  塔体 / 导线 / 绝缘子 / 跳线
  校验 PowerLineValidator（间距、地形、垂度、转角、导线重叠）
```

默认 `lineChecksEnabled` 与 `terrainAvoidanceEnabled` 均为 **true**。预览用 `PowerLinePreviewKey`；检查报告用 `PowerLineAnalysisKey` 绑定同一份预览。

## 仍存在的问题

### P1

#### P1-1 用户向导没有电力线路

`docs/zh/08-plugins.md` 与 `docs/en/08-plugins.md` 的已安装插件表只有土方 / 道路 / 建筑，并写「所有插件都是概览 / 认领 / 编辑 / 生成」。电力线路实际是 **概览 / 线路 / 样式 / 建造**。玩家从用户文档进不了这个插件。

**建议**：补一节典型流程（画折线 → 线路 Tab 认领 → 样式 → 建造预览），并改掉「四个插件都同一套 Tab」那句。

---

### P2

#### P2-1 工程画布叠加不判断当前扩展

`PowerLinePlugin` 注册 overlay 后，只要本插件仍 enable，切到道路/土方也会画（若 overlay 打开且有有效报告）。土方叠加会检查 `getActivePlugin()`。

**位置**：`PowerLinePlugin` 的 `engineeringOverlay`。

#### P2-2 建造确认读未校验的地形报告

工程报告走 `cachedEngineeringReport`（带 AnalysisKey）。地形报告直接 `getValidationState().getLastTerrainReport()`。清预览会一起清，正常路径一致；一旦两套 key 分叉，确认框可能用过期地形计数。`issueCount` 在工程有问题时报工程数，地形另计，两者同时有问题时不会加总。

**位置**：`PowerLineBuildActions.renderBuildConfirmPopup`。

#### P2-3 地形开关出现两次

线路 Tab 有「避开地形」；建造高级检查里又有「地形净空」复选框，写的是同一个 `terrainAvoidanceEnabled`。玩家容易以为是两套功能。

#### P2-4 建造页杆数写两遍

`renderRouteProjection` 与 `renderPreviewSummary` 在有预览时都显示杆数。可把摘要里的杆数拿掉，或投影条只在无预览时显示估计值。

#### P2-5 死方法 `renderAdvancedEngineeringSection`

`PowerLineUiWidgets` 里仍有完整实现，全仓库无调用。Javadoc 还写「Engineering 标签页」。应删，或接到高级检查以免两套控件。

#### P2-6 「拾取路径」仍是通用选择工具

`activatePathPickTool` 只 `setActiveTool(select)`，没有高亮可认领折线、没有结束态。有 hint 文案，比上一轮好，但和道路的 Pick Session 仍不在一个量级。

#### P2-7 叠加层默认关，检查默认开

`lineChecksEnabled` / `terrainAvoidanceEnabled` 默认 true，`overlayEnabled` 默认 false。画布上没有检查结果，除非玩家翻到高级检查打开叠加。

#### P2-8 杆塔设计保存不进线路撤销

设计器内部有 `PoleDesignDraftHistory`（窗口内撤销）。`savePoleDesign` 仍不 `push` 线路工程历史。线路 Tab 撤销不会还原自定义杆型。

#### P2-9 设计工程保存失败几乎静默

`persistProject` / `onProjectSaved` 对 `saveDesignProjectFile` 的失败没有状态条。加载失败已有 `loaded_designs_failed` 警告。

#### P2-10 测试仍不覆盖 UI Actions 热路径

有 PreviewKey / AnalysisKey / estimatePoleCount / FriendlyStatus / 弹窗 helper 的单测。没有测试：`calculatePreview` 不改 footprint、`autoAdjustTerrain` 才 push 历史、`clearPreview` 清报告。这些现在是正确行为，但没有回归锁。

## 值得保留

1. **预览只读 + 修正显式化**：`calculatePreview` / `autoAdjustTerrain` 分离，历史只在真的改线时 push。
2. **`PowerLinePreviewKey` + `PowerLineAnalysisKey`**：幽灵和检查报告绑在同一参数指纹上。
3. **确认弹窗 helper**：统一 `openPopup` 一次、每帧 `beginPopupModal`。
4. **加杆可见可删**：约束列表 + 概览杆位与生成一致。
5. **生成警告 i18n token**（`PowerLineGenerationI18n`），不再把英文塞进预览列表。
6. **状态条按严重度上色**（`ProjectStatusSeverity`）。
7. **JSON `schemaVersion`（线路 v4、设计工程也有版本）**。
8. **设计器可关、有未保存确认、窗口内撤销**。
9. **认领钮在不可认领时 disabled**，并提示 unsupported / 曲线。
10. **角色 combo 长度与 `TowerRole` 对齐**。

## 建议优先级

1. 用户向导补电力线路（P1-1），顺手改 Tab 名称。
2. overlay 仅在本插件为当前扩展时绘制（P2-1）。
3. 建造确认地形报告改走 `cachedTerrainReport`；问题数加总（P2-2）。
4. 删掉 `renderAdvancedEngineeringSection`；线路 Tab 地形开关与高级检查合并文案（P2-3 / P2-5）。
5. 给 `autoAdjustTerrain` / `clearPreview` 补一条 Actions 级单测（P2-10）。

主路径（认领、预览、建造、地形修正、加杆）可以认为已经稳定，不必再为上一轮那批 P1 返工。
