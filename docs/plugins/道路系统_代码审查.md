# 道路系统插件 · 代码审查

> **状态**：2026-09-21 重构后全面复查  
> **范围**：`com.plot.plugin.RoadSystemPlugin`、`com.plot.plugin.road.*`、`RoadSystemConfig`、测试、用户向导 `docs/zh|en/08-plugins.md`  
> **结论**：主路径可用。三 Tab（路径 / 编辑 / 生成）、快照预览、平面线形/路口一致性、分帧预览与落地阻断都已成型。下面按 P0/P1/P2 记仍开放项；没有发现会直接写坏 live 路网的生成路径问题。

## 当前架构

```
RoadSystemPlugin
  ├ RoadNetworkManager     live 路网单写者 + 撤销
  ├ RoadPreviewManager     快照上分帧预览 / 虚影 / 落地
  ├ RoadPersistenceManager 工程 sidecar networks/*.json
  ├ RoadToolManager        路径拾取
  └ RoadUIManager
        PATH  — 认领、道路列表、路口、路网缩略图
        EDIT  — 预设、横断面、材质、平面/纵断面设计
        GENERATE — 预览、校验、纵断面、确认后落地
              RoadNetworkGenerator
                snapshot() → DerivedCenterlineSynchronizer
                RoadEdgeBuildOrchestrator
                  RoadProfileSolveCoordinator
                  RoadGenerationPipeline
                    Sampler → Classifier → CrossSection
                    Marking / Furniture / Station / Terrain / Raster
                RoadJunctionGenerator
```

数据目录：

- 全局配置：`.minecraft/config/plugins/road_system.json`
- 项目路网：`.minecraft/plot/plugins/road_system/networks/`（按工程路径 sidecar）

## 重构里已经做对的

| 点 | 证据 |
|----|------|
| 预览不改 live 派生中心线 | `RoadNetworkGenerator.beginPreviewSession` 先 `network.snapshot()`，`DerivedCenterlineSynchronizer` 只写快照 |
| 生成失败不全网落地 | `hasPartialFailure()` 时预览警告、建造按钮禁用、`buildRoadInWorld` 再挡一层 |
| 生成前硬校验 | `analyzePreGeneration` 在预览启动与落地两处执行 |
| 路口与 HA 冲突不静默贴合 | `HorizontalAlignmentCenterlineMaterializer` all-or-nothing；共享节点以 `RoadNode.position` 为权威 |
| 路网变更事务 | `mutateNetwork` / `pushUndoSnapshot` + `commitNetworkChange`；失败中心线编辑不 bump revision（有单测） |
| 认领失败回滚 | `adoptSelectedPaths` 每条认领前 JSON 快照，失败 `parseSnapshot` 还原 |
| 画布叠加层只在本插件激活时画 | `RoadSystemPlugin.renderRoadOverlay` 检查 `getActivePlugin()` |
| 管线分层 | `RoadGenerationPipeline` 阶段清晰，`RoadGenerator` 仍是对外门面 |
| 测试 | golden / pipeline / HA / 纵断面 / Manager 事务 / 持久化覆盖面很大 |

## 仍开放

### P1

| 项 | 说明 | 建议 |
|----|------|------|
| 用户向导仍是四 Tab | `docs/zh/08-plugins.md` 写「概览 / 认领 / 编辑 / 生成」，并写「在认领标签页沿路径认领」。实现已是 **路径 / 编辑 / 生成**（`RoadUiTab`）。土方/建筑那句「四标签」也还在。 | 改向导：路径 = 认领+列表+路口；编辑 = 横断面/风格；生成 = 预览落地。补平面线形、平路/地形自适应、路口属性面板。 |
| 确认弹窗仍用 `openPopup` | `RoadGeneratePanel.renderBuildConfirmPopup`、`RoadNetworkToolsPanel`、`RoadVerticalStrategySwitchDialog`、`RoadEdgeListPanel.renderDeleteConfirmPopup` 都是 deferred 里 `ImGui.openPopup` + `beginPopupModal`。电力线路同类问题已改为 `beginDeferredPopupModal`。 | 抽公共 deferred modal，或复用电力线路那套，避免弹窗偶发打不开。 |
| 校验一键修复绕过事务协议 | `RoadValidationMessageUi.executeAction` 对 `MATERIALIZE_ALIGNMENT` / `SMOOTH_GRADE` / `SYNC_SEGMENT_ORDER` 先 `pushHistory()` 再改 live 网络。`pushHistory` 会立刻 bump revision 并失效预览；物化失败时路网没变，撤销栈却多一帧空操作。Manager 已有 `materializeHorizontalAlignment` + `mutateNetwork(..., isSuccess)`。 | 一键修复走 Manager API；失败不 commit。 |
| 画布走廊与生成中心线不是同一套 | 生成：`RoadPlanGeometry.resolveEdgeCenterline`（有 HA 用设计线）。叠加层走廊：`RoadCenterlineShapeValidator.buildChainedCenterline`（实例折线）。箭头才走 plan 中心线。HA 未点「物化」时，画布路宽包络可能和预览/落地错开。这是旧「HA vs 路口中心线」问题的残留表面。 | 走廊也走 `resolvePlanCenterline`；或 HA 编辑提交时自动物化（失败则保持按钮+报冲突）。 |

### P2

| 项 | 说明 |
|----|------|
| 切走插件不关道路虚影 | `onDeactivate` 只静默取消预览 job，不 `clearPreview()`。叠加层不画了，世界里 ghost 还在。 |
| JSON 无 `schemaVersion` | `RoadNetworkPersistence` 仍直接 `toJson`/`fromJson`，注释写「后续 format v2」。新字段靠 Gson 缺省，没有迁移钩子。 |
| 叠加层晚一帧 | `refreshOverlayForCanvas` 是空的；snapshot 在插件 UI 末尾。画布先于面板绘制。宽度滑条靠 `renderDeferredOverlay` 补，点击选路仍可能点到上一帧几何。 |
| `RoadOverviewPanel` 文案过时 | 类注释仍写「概览 Tab」。现在只给路径 Tab 画缩略图，健康摘要/捷径不再是独立 Tab。 |
| 生成 Tab 纵断面入口重叠 | 同时有 `VerticalAlignmentEditor`、inline `VerticalProfileEditor`、以及独立 profile 窗口。能用，但路径 Tab 已有纵断面策略切换，用户要找三处。 |

### P3

- 用户向导未写平路推荐、立交净空、复杂路口合并、土方走廊采样。
- 同一画布路径可重复认领（有拓扑修复，但 UI 未说明）。
- 预览分帧在主线程（World 采样限制），大路网仍会卡几帧；有 progress UI，可接受。

## 主路径对照（抽检）

| 步骤 | 行为 | 判定 |
|------|------|------|
| 认领折线 | `RoadToolManager` → `adoptSelectedPaths`，求交不完整则 `adoptIntersectionRepairPending` | 通过 |
| 改路宽/预设 | `CrossSectionDraftMutator` + `pushRoadEditHistory` | 通过 |
| 计算预览 | 硬校验 → 快照生成 → ghost | 通过 |
| 路网编辑后预览 | `onNetworkChanged` → `invalidatePreview` 清虚影 | 通过 |
| 部分边失败 | 建造禁用 | 通过 |
| 落地 | `GenerateRoadCommand.executeScheduled` + `pushExecuted`；取消也可撤销已写块 | 通过 |
| 工程切换 | 文件不存在 → 空路网；损坏 → 不改 `currentNetworkFile`，避免把旧路网写入新工程 | 通过 |

## 建议下一刀（按收益）

1. 改用户向导三 Tab，避免按旧「认领」找不到入口。  
2. 确认/删除/策略切换弹窗改 deferred modal。

4. 画布走廊改 plan 中心线，或 HA 提交时自动物化。

自动化测试锁得住生成几何，锁不住「弹窗是否弹出」和「画布包络是否跟 HA 一致」。这两项要游戏内点一次。
