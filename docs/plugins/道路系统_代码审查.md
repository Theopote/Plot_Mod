# 道路系统插件 · 代码审查

> **状态**：2026-09-29 重构后全面复查  
> **范围**：`com.plot.plugin.RoadSystemPlugin`、`com.plot.plugin.road.*`、`RoadSystemConfig`、测试、用户向导 `docs/zh|en/08-plugins.md`  
> **结论**：主路径可用。三 Tab（路径 / 编辑 / 生成）、快照预览、平面线形/路口一致性、分帧预览与落地阻断都已成型。下面按 P0/P1/P2 记仍开放项；没有发现会直接写坏 live 路网的生成路径问题。

## 当前架构

```
RoadSystemPlugin
  ├ RoadNetworkManager     live 路网单写者 + 撤销
  ├ RoadPreviewManager     快照上分帧预览 / 虚影 / 落地
  ├ RoadPersistenceManager 工程 sidecar networks/*.json
  ├ RoadToolManager        路径拾取
  └ RoadUIManager
        PATH  — 认领、道路列表、路口、路网缩略图
        EDIT  — 预设、横断面、材质、平面/纵断面设计
        GENERATE — 预览、校验、纵断面、确认后落地
              RoadNetworkGenerator
                snapshot() → DerivedCenterlineSynchronizer
                RoadEdgeBuildOrchestrator
                  RoadProfileSolveCoordinator
                  RoadGenerationPipeline
                    Sampler → Classifier → CrossSection
                    Marking / Furniture / Station / Terrain / Raster
                RoadJunctionGenerator
```

数据目录：

- 全局配置：`.minecraft/config/plugins/road_system.json`
- 项目路网：`.minecraft/plot/plugins/road_system/networks/`（按工程路径 sidecar）

## 重构里已经做对的

| 点 | 证据 |
|----|------|
| 预览不改 live 派生中心线 | `RoadNetworkGenerator.beginPreviewSession` 先 `network.snapshot()`，`DerivedCenterlineSynchronizer` 只写快照 |
| 生成失败不全网落地 | `hasPartialFailure()` 时预览警告、建造按钮禁用、`buildRoadInWorld` 再挡一层 |
| 生成前硬校验 | `analyzePreGeneration` 在预览启动与落地两处执行 |
| 路口与 HA 冲突不静默贴合 | `HorizontalAlignmentCenterlineMaterializer` all-or-nothing；共享节点以 `RoadNode.position` 为权威 |
| 路网变更事务 | `mutateNetwork` / `pushUndoSnapshot` + `commitNetworkChange`；失败中心线编辑不 bump revision（有单测） |
| 认领失败回滚 | `adoptSelectedPaths` 每条认领前 JSON 快照，失败 `parseSnapshot` 还原 |
| 画布叠加层只在本插件激活时画 | `RoadSystemPlugin.renderRoadOverlay` 检查 `getActivePlugin()` |
| 管线分层 | `RoadGenerationPipeline` 阶段清晰，`RoadGenerator` 仍是对外门面 |
| 测试 | golden / pipeline / HA / 纵断面 / Manager 事务 / 持久化覆盖面很大 |

## 主路径对照（抽检）

| 步骤 | 行为 | 判定 |
|------|------|------|
| 认领折线 | `RoadToolManager` → `adoptSelectedPaths`，求交不完整则 `adoptIntersectionRepairPending` | 通过 |
| 改路宽/预设 | `CrossSectionDraftMutator` + `pushRoadEditHistory` | 通过 |
| 计算预览 | 硬校验 → 快照生成 → ghost | 通过 |
| 路网编辑后预览 | `onNetworkChanged` → `invalidatePreview` 清虚影 | 通过 |
| 部分边失败 | 建造禁用 | 通过 |
| 落地 | `GenerateRoadCommand.executeScheduled` + `pushExecuted`；取消也可撤销已写块 | 通过 |
| 工程切换 | 文件不存在 → 空路网；损坏 → 不改 `currentNetworkFile`，避免把旧路网写入新工程 | 通过 |

## 建议下一刀（按收益）

1. 用户向导补平路推荐、立交净空、复杂路口合并等高级能力说明。  
2. format v2 字段迁移（在现有 `schemaVersion` 钩子上扩展）。  
3. HA 物化失败时的 inline 冲突提示（自动物化静默跳过时保留手动按钮）。

自动化测试锁得住生成几何，锁不住「弹窗是否弹出」和「画布包络是否跟 HA 一致」。这两项要游戏内点一次。
