## 仍存在的问题

### P1 生成 / 几何

#### P1-1 洞门前回填把过渡带封成衬砌盖

`TunnelPortalBackfillPass.sealPortalSite` 沿洞门 `forward` 做：

```text
for (int step = -transitionBand; step <= transitionBand; step++)
```

`PORTAL_TRANSITION_CLEAR_BAND_BLOCKS = 8`。正负两侧都会调用 `TunnelRoofGapSealer.sealAboveRoofShell`，在 `designY` 拱顶高度写衬砌 / `minecraft:stone`。

负向（进山）是回填过挖；正向落在洞门前方开敞段，会在隧道顶高处铺一层边坡/衬砌观感的盖板。仓库里没有 `TunnelPortalBackfillPass` 测试。

**建议**：只对山体一侧（或 `PortalTransitionGuard` 判定的 preserve 列）封顶；洞门前方 OPEN 走廊不要写屋顶壳。

#### P1-2 平交铺面在路口多边形内混入引道剖面 Y

`RoadJunctionGenerator.fillJunctionCells`：立交 `elevationBlendRadius = 0`；平交半径为 `junctionRadius + cornerRadius`，覆盖整块铺面。

`JunctionCellElevationResolver.resolve` 在半径内 `smoothStep` 混 `junctionY` 与引道 `buildProfile` Y；半径外直接用引道剖面。中心是共识标高，外围跟着各臂走，铺面不再是一个平面。

这与 2026-10-16 已关闭的「平交必须同一 `junctionY`」相反，是路口残差 / 可行域提交后重新打开的混合。十字、丁字、多路、自交平交都走这条。

**建议**：铺面格固定 `junctionY`；引道纵坡在 trim 边界外衔接。若保留混合，混合半径必须小于 skip，且 skip 与多边形一致。

#### P1-3 走廊 trim 比路口多边形多约 1 格

`JunctionCorridorTrim.skipDistanceAtNode`：

```text
max(行车道 + 外侧条带 + 0.5,
    max(DEFAULT_JUNCTION_RADIUS, maxHalfWidth + 1) + corner + 1.0)
```

排除多边形用 `resolveEffectiveJunctionRadius` + `cornerRadius`，没有最后的 `+ 1.0`。边在路口外多空一圈：走廊不铺，路口多边形也扫不到。清场只打多边形内，这一圈原地形和错层实体会留下。

上跨路 `shouldTrimAtEndpoint` 为假，skip = 0，走廊穿过交点；平交/下穿才会露出这圈空隙。

**建议**：skip 与 `buildJunctionFillPolygon` 用同一套半径；不要在 skip 上再加 1。

#### P1-4 立交标志可能静默失败，上跨重新被拉成 V

`RoadNetwork.setNodeGradeSeparation` 在 `!RoadGraphQueries.isSimpleCrossing` 时直接 `return false`。简单交叉定义：度数 4、恰好 2 个 `roadId`、每个 2 条边。

`RoadCrossingMaterializer.applyCrossingDesignToJunction` 在拆边之后调用，返回值丢掉。T 形、三路、拆边失败、自环未拆成四臂时，注册表已是 `GRADE_SEPARATED`，节点仍是平交。

后果：`skipSnapForElevatedRoad` 不触发；`degree ≥ 3` 端点吸附到 `networkNodeElevations`（下穿层）；上跨在交点落到下穿标高，呈 `--\_/--`。

`GradeSeparationPolicy.retainDesignedUpperHeight` 只在该节点已有 VA 时抬到设计高程。`AUTO` 且无 VA 时上跨只有 `underpassY + clearance`。标志失败时连这一档都没有。

**建议**：物化失败要记入预览/校验；T / 复杂口允许立交或明确拒绝并提示；禁止吞掉 `setNodeGradeSeparation` 的 false。

#### P1-5 路口空结果不记 skip

`RoadJunctionGenerator.generateJunction` 在 `degree ≤ 2` 或 `collectUnderpassJunctionEdges` 为空时返回空 `JunctionBlocks`。

`RoadNetworkGenerator.tickPreviewSessionJunctions` 只在「相连边生成失败」时 `recordSkippedJunction`。空铺面不进 `junctionResults`，也不进 `skippedJunctionIds`。`hasPartialFailure` 看不到「立交下穿臂全被当成上跨」或「自环没拆开」。建造守卫放行，交点没有铺面。

**建议**：空铺面记 skip 或校验项，并挡住落地。

#### P1-6 挖填包络仍不含边坡外缘

`RoadCorridorWidth.gradingEnvelopeWidthBlocks` = 行车道 + 外侧条带 ×2，不含 `includeSlopeBatter`。植被清理 `decorationClearWidthBlocks` 才加边坡裕量。走廊计划若漏采边坡列，原地形会留在坡面上。

城市预设 `RoadStyleCatalog.base()` 的 `fillSlopeRatio` / `cutSlopeRatio` 为 0，`includeSlopeBatter = null`，`resolveIncludeSlopeBatter()` 为假。公路/山地/乡村显式打开边坡。

**建议**：需要边坡的风格把挖填包络对齐边坡外缘；城市风格保持 0，并让预览与生成一致（见 P2-3）。

### P1 UI

#### P1-7 生成页把建造按钮埋在全部纵断面卡片后面

`RoadGeneratePanel.render` 顺序：状态卡 → 范围 → 生成设置（桥柱/护栏/隧道/实验项）→ 计算/清除预览 → **所有可桩号道路的纵断面卡片** → 当前路的坡度/来源/平路基准 Y → 交叉口检查（只跳到路径 Tab）→ 摘要与建造。

`RoadProfileOverviewSection` 对每条可桩号道路画一张卡。路一多，计算预览和建造之间隔着整页图表。建造还要求 `isBuildPreviewCurrent`，用户改完卡片后要滚回去找按钮。

**建议**：把状态、计算预览、建造钉在顶部或底部操作条；卡片单独滚动。交叉口检查改成可展开摘要，或提供「在本页改平交/立交」而不是只跳转。

#### P1-8 纵断面三套概念叠在两个 Tab

| 入口 | 控件 | 实际写入 |
|------|------|----------|
| 路径 Tab | `VerticalAlignmentEditor.renderPathProperty` | `RoadVerticalStrategy`（适应地形 / 平路）+ 平路 Base Y |
| 生成 Tab | `ProfileSourceControls` | `ProfileSource` AUTO / EDITED |
| 生成 Tab | `VerticalModeControls` | 再次提供平路 Base Y |
| 模型 | `RoadVerticalMode` | `FLAT` / `FIT_TERRAIN` / `AUTO_SMOOTH` / `MANUAL_PROFILE` |

生成概览注释写明不画绿色设计线：「玩家曲线仅在纵断面编辑器中出现」。用户在编辑器里改绿线并确认会重算预览，但 `ProfileSource` 仍是 AUTO 时，生成快照剥离 VA，灰线按自动求解，绿线意图被丢掉。过期曲线有 `stale_reconfirm` 提示，首次确认后未切到 EDITED 的路径没有同等强度的拦截。

**建议**：适应地形在生成页把「用我刚确认的曲线」设为确认后的默认；路径 Tab 只留策略开关；平路 Base Y 只留一处。

#### P1-9 交叉口编辑只有路径 Tab 有完整控件

- 路径：列表 + `RoadIntersectionDetailPanel`（两路 / 自交 / 旧节点）+ 立交控件
- 编辑：选中路口节点只给 hint +「去交叉口」跳回路径
- 属性侧栏：`RoadNodePropertyPanel` 只编节点标高，立交同样 hint 去路径
- 生成：交叉口检查按钮 `requestTab(PATH)`
- 复杂口：`ComplexJunctionGuidePanel` 只挂在 `renderLegacyJunction` 的非简单交叉

三个 Tab 都能碰到交叉口，只有路径能改平交/立交。生成页在落地前最需要确认立交，却不能改。

**建议**：生成页交叉口检查列出每处平交/立交并可切换；属性侧栏复用同一组立交控件。

#### P1-10 纵断面编辑器会跟着主选择抢路

`VerticalProfileEditor.ensureEditorRoadSelection`：主选道路可桩号且与 `editorRoadId` 不同时，立刻 `selectEditorRoad`。窗口开着时，路径列表或画布改主选会换掉正在编的路。拖 PVI 中途切路会丢掉未确认编辑（关窗有确认，切路这条没有同等提示）。

窗口本身：`NoDocking | NoSavedSettings | NoCollapse`，尺寸 0.6 屏（0.4–0.9），图高 0.72。布局已经收紧。问题在选择同步，不在尺寸。

**建议**：编辑器内的道路下拉是权威；主选变化只提示「切换到当前选择」，不要自动覆盖。

### P2

#### P2-1 检测器默认平交

`RoadCrossing.atGrade` / `RoadStackCrossing` / reconciler 在 `type == null` 时写 `AT_GRADE`。立交必须事后在路径 Tab 改。与 P1-9 叠加：没打开路径 Tab 的用户会一直得到平交清场。

#### P2-2 `ShortcutManager.getInstance()` 违反 ADR 0001

`RoadSystemPlugin.onEnable` / `onDisable` 对拾取 Escape 监听器用 `ShortcutManager.getInstance()`。`renderDeferredModals` 用 `PluginManager.getInstance().getActivePlugin()` 判断叠加层。ADR 要求插件经 `PluginContext` 访问 Core，禁止新增 `*.getInstance()`。土方 / 电力 / 建筑同样有 `PluginManager.getInstance()`，道路这条是新增快捷键定位器。

#### P2-3 城市预设预览边坡测试仍在

`RoadCrossSectionPreviewRendererTest.urbanPresetsDoNotShowSpuriousSlopeBatter` 仍断言 `cityMain` / `residential` / `park` 的 `includeSlopeBatter == false`。`fromStyle` 先 `style.resolveIncludeSlopeBatter()`（城市为假），再 `ResolvedCrossSection.resolve(section, defaults)`，全局默认可能把边坡打开。乡村/公路显式 `includeSlopeBatter = true`。

#### P2-4 桥跨表面掩膜测试仍在

`RoadCorridorPlanBuilderTest.bridgeSpanProducesContinuousSurfaceMask` 要求桥跨 X=8..22 连续 ROAD 掩膜（至少 14 列）。2026-10-16 记录为 65 vs 85。本轮未重跑，测试源仍在。

#### P2-5 管线 javadoc 与空 `RoadTerrainGrader`

`RoadGenerationPipeline` 类注释仍画 `RoadTerrainGrader`。`grade()` 只有一句「走廊管线已接手」，全仓库无调用。`RoadTerrainGrader` 仍留私有 `GradingHost` 与挖填实现，属于死代码。

#### P2-6 工具栏路网撤销出现在所有 Tab

`RoadToolbarPanel` 在 Tab 栏上方始终画路网撤销/重做；世界撤销仅在 `canUndoWorldPlacement` 时出现。生成页的撤销容易与落地撤销搞混。文案有 `undo_scope_hint`，两个按钮仍并排占满宽。

#### P2-7 画布走廊半宽不含边坡时与生成包络不一致

`canvasPreviewHalfWidthBlocks` 不含路肩/排水/边坡；`overlayHalfWidthBlocks` 在 `includeSlopeBatter` 时加边坡。挖填包络仍不含边坡（P1-6）。叠加层比实际开挖窄或宽，取决于风格。

#### P2-8 浅桥 / 整数 Y / 结构最短段

既有生成观感项仍在：浅桥可能不铺板、Y 取整台阶、`MIN_STRUCTURE_RUN`、简单包络回退仍可能走画布整数格、全程未加载剖面回退 64。本轮重构未改这些产品锁。玩家原木柱继续保持。

## UI 结构对照

| Tab | 实际职责 | 不合适处 |
|-----|----------|----------|
| **路径** | 拾取认领、道路列表、总览图、纵向策略、交叉口完整编辑 | 纵向策略与生成页平路 Base Y 重复；交叉口能力只在这里 |
| **编辑** | 预设、横断面、材质、设施、高级设计 | 选中路口只有跳转 hint，没有属性 |
| **生成** | 全局结构开关、预览、全部纵断面卡、来源、建造 | 卡片把建造挤下去；绿线不在概览；交叉口只能跳走 |
| **浮动纵断面窗** | 绿线、PVI、交叉标记、体素预览（条件） | 跟着主选换路 |
| **属性侧栏** | 节点标高、圆角/标线 | 立交只能去路径 Tab |
| **顶栏** | 路网撤销；有世界改动时世界撤销；预览进度 | 三 Tab 都显示路网撤销 |

校验一键修复 `RoadValidationMessageUi` 仍在，含路网级下钻与平交冲突行。生成确认弹窗与主按钮都看 `isBuildPreviewCurrent` 和 `hasPartialFailure`。

## 建议处理顺序

1. **P1-1** 洞门前回填方向：去掉洞口前方屋顶壳，观感立刻干净。  
2. **P1-3 + P1-2** 平交：skip 对齐多边形，铺面固定 `junctionY`。这是路口「清不干净 / 标高乱」的现码根。  
3. **P1-4 + P1-5** 立交标志失败与空路口 skip：避免 V 形下陷和静默缺铺面。  
4. **P1-7 + P1-8 + P1-9** 生成页操作条、确认后默认 EDITED、交叉口就地切换。  
5. P2 死代码、ADR、城市边坡测试、桥跨掩膜。

未接到「开始改 / 请你修复」之前，不改生产代码。
