## 一句话

三 Tab 主路径、快照预览、过期建造守卫、纵断面确认重算、立交上跨跳过端点吸附，这些已经能走通。当前没有挡住「能生成」的 P0。路口铺面已固定 `junctionY`、洞门只封山体一侧、生成页可就地切立交、边坡列按坡面清场。还剩画布半宽与叠加层不一致，以及检测器默认平交、浅桥与整数 Y 等产品锁。

```

```

数据目录：

- 全局配置：`.minecraft/config/plugins/road_system.json`
- 项目路网：`.minecraft/plot/plugins/road_system/networks/`

产品 Tab：`RoadUiTab` = PATH / EDIT / GENERATE。用户向导 `docs/zh/08-plugins.md`、`docs/en/08-plugins.md` 已按三 Tab 写。

纵断面权威：

| 层 | 类型 | 作用 |
|----|------|------|
| 产品策略 | `RoadVerticalStrategy` | 适应地形 / 平路 |
| 求解模式 | `RoadVerticalMode` | `FLAT` / `FIT_TERRAIN` / `AUTO_SMOOTH` / `MANUAL_PROFILE` |
| 曲线来源 | `ProfileSource` | `AUTO` / `EDITED`，与求解模式解耦 |

生成快照上 `ResolvedProfileAuthority.usesEditedProfileForGeneration` 为假时，`VerticalProfileGenerationPolicy` 剥离 dormant VA。`EDITED` / `MANUAL_PROFILE` 走 `RoadHeightRasterizer.followDesign`。

交叉口：

| 类型 | 注册 | 节点元数据 | 生成意图 |
|------|------|------------|----------|
| 两路平交 | `RoadCrossing` `AT_GRADE` | 共识 `junctionY` | 路口铺面 |
| 两路立交 | `GRADE_SEPARATED` | `isGradeSeparated` + 上跨路 + 净高 | 下穿铺面；上跨走廊 |
| 自交平交 | `RoadStackCrossing` 默认 `AT_GRADE` | 四臂 | 与十字平交相同 |
| 自交立交 | `GRADE_SEPARATED` | `isStackGradeSeparated` + 上下臂 | 下穿铺面；上臂走廊抬升 |

检测器一律写出平交；立交靠路径 Tab 或生成页交叉口区改注册表。叠加层两路交叉与自交共用 `selectedCrossingId`。

## 仍存在的问题

### P2

#### P2-1 检测器默认平交

`RoadCrossing.atGrade` / `RoadStackCrossing` / reconciler 在 `type == null` 时写 `AT_GRADE`。立交仍须用户在路径或生成页交叉口区改。生成页已能就地切换，不再完全依赖路径 Tab。

#### P2-7 画布走廊半宽不含边坡时与生成包络不一致

`canvasPreviewHalfWidthBlocks` 不含路肩/排水/边坡；`overlayHalfWidthBlocks` 在 `includeSlopeBatter` 时加边坡。挖填包络 `earthworkEnvelopeWidthBlocks` 已含边坡；画布路径预览仍偏窄。

#### P2-8 浅桥 / 整数 Y / 结构最短段

既有生成观感项仍在：浅桥可能不铺板、Y 取整台阶、`MIN_STRUCTURE_RUN`、简单包络回退仍可能走画布整数格、全程未加载剖面回退 64。本轮重构未改这些产品锁。玩家原木柱继续保持。

土方 / 电力 / 建筑仍有 `PluginManager.getInstance()`，不在本插件范围内。

## UI 结构对照

| Tab | 实际职责 | 不合适处 |
|-----|----------|----------|
| **路径** | 拾取认领、道路列表、总览图、纵向策略、交叉口完整编辑 | 纵向策略与生成页平路 Base Y 仍重复 |
| **编辑** | 预设、横断面、材质、设施、高级设计 | 选中路口只有跳转 hint，没有属性 |
| **生成** | 全局结构开关、预览、摘要 + BUILD、纵断面卡、交叉口就地编辑 | 平路 Base Y 与路径 Tab 重复；属性侧栏仍无立交控件 |
| **浮动纵断面窗** | 绿线、PVI、交叉标记、体素预览（条件） | 脏会话不再跟主选抢路 |
| **属性侧栏** | 节点标高、圆角/标线 | 立交只能去路径或生成页 |
| **顶栏** | 路网撤销（生成页紧凑）；有世界改动时世界撤销；预览进度 | 路径/编辑仍全宽路网撤销 |

校验一键修复 `RoadValidationMessageUi` 仍在，含路网级下钻与平交冲突行。生成确认弹窗与主按钮都看 `isBuildPreviewCurrent` 和 `hasPartialFailure`。
