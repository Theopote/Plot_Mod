# 铺装图案插件 · 代码审查

> **日期**：2026-09-16（P1 收尾 + P2 增强后复审）  
> **范围**：`com.plot.plugin.PatternPlugin`、`com.plot.plugin.pattern.*`、对应测试、i18n、用户向导  
> **结论**：四 Tab 主路径可用。P1 文档/诊断/区块回退/棋盘格/认领校验已落地；P2 完成 first-claim 合并、重叠检测加强、孔洞采样、圆心 UI、建造弹窗预检。无 P0。

## 一句话

认领闭合区 → 程序化或导入图 → 预览（幽灵）→ 确认落地，与道路/建筑插件同一套撤销与 owner 隔离。剩余问题主要是 **孔洞无编辑 UI**、**重复认领同一图形**、以及 **CONTAIN 留白无示意图** 等产品层说明。

## 架构（当前）

```
PatternPlugin
  └ PatternUIManager (概览 / 认领 / 编辑 / 生成)
        PatternActions / PatternGenerator
              PatternMaterialResolverFactory
              PatternGenerationPipeline
                PatternSampling → PatternMaterialResolver
                TerrainSurfaceProjector → PatternPlacementRecorder
              PatternGenerateCommand (appliedRecords + successfulIndices)
```

数据：`.minecraft/plot/plugins/pattern/projects/`、图片 sidecar 在 `images/`。

### P3（后续产品/UX）

#### P3-1 单图形多环

认领时已支持多图形外环+内环自动分组；单条闭合折线上的多个子环仍无法解析。

#### P3-2 同一闭合形可重复认领

认领不 dedupe 相同 `outerPoints`；重叠检测仅警告。可选：拒绝完全重合或提示合并。

#### P3-3 预览合并顺序依赖选中顺序

first-claim 按 `calculatePreview` 迭代顺序；多选时「先认领的 footprint 在列表靠前则优先」——需在 UI 说明或提供优先级。

#### P3-4 CONTAIN 留白

设计如此（保持比例居中），但无示意图，不规则多边形四周空白易误解为 bug。

#### P3-5 条纹角度 vs 世界北向

画布 XZ 坐标系，与世界北向不一定对齐；编辑页仅有角度滑条，无罗盘参考。

#### P3-6 JSON 无 schemaVersion

与电力线路 v4 不同；字段演进靠 Gson 默认值，大改时需迁移脚本。

## 值得保留

1. **Pattern Space 与世界投影分离**，单测锁定采样坐标语义。  
2. **程序化四种算法 + 图片三 fit**，马赛克走共享 `MaterialMixResolver`。  
3. **落地** `PatternGenerateCommand` + `GhostBlockOwners.PATTERN`，部分失败只撤销成功格。  
4. **`getPattern()` / `getImagePattern()` 返回 copy**，编辑 commit 写回。  
5. **项目 JSON** sidecar、原子写、fingerprint 跳过无变更保存（`PatternProject`）。  
6. **图片导入** `MinecraftClient.execute()` 回主线程写 UI 状态。

---

## 建议优先级

1. 重复认领策略（警告 / 拒绝 / 合并）  
2. CONTAIN 模式示意图或预览框  
3. 多 footprint 优先级说明或拖拽排序  
4. `schemaVersion` + 迁移（与其它插件对齐）
