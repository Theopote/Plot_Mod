## 当前架构

```
PatternPlugin
  └ PatternUIManager (区域 / 图案 / 生成)
        PatternRegionPanel — 认领、孔洞、区域列表
        PatternDesignPanel — 预设、图案参数、边框 v1
        PatternGeneratePanel — 预览与落地
        PatternActions / PatternGenerator
              PatternMaterialResolverFactory
              PatternGenerationPipeline
                PatternSampling → BorderSampler → MaterialResolver
                TerrainSurfaceProjector → PatternPlacementRecorder
              PatternGenerateCommand (appliedRecords)
```

数据目录：

- 项目：`.minecraft/plot/plugins/pattern/projects/`（`schemaVersion`）
- 区域图片：`images/`
- 预设图片：`preset-assets/`
- 用户预设：`presets/user_presets.json`
- 内置预设：代码 `BuiltInPatternPresets`（固定 ID + i18n）
