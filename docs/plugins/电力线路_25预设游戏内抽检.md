# 电力线路 — 25 Preset 游戏内抽检 Checklist

> **用途**：PL-TOWER-S1 / PL-BLOCKSTATE-S1 关闭前的**最后一道人工验收**。  
> **前提**：本地 `./gradlew test --tests "com.plot.plugin.powerline.*"` 已绿。  
> **通过标准**：玩家不看工程面板也能说「这就是 Style 卡片上那种线」；BlockState 重点项 F3 无裸方块朝向错误。

相关文档：[风格一致性验收](电力线路_风格一致性验收.md) · [BlockState S1](电力线路_BLOCKSTATE-S1.md)

## 抽检前准备（一次性，约 3 分钟）

- [ ] 平坦测试世界，白天，创造模式或足够材料
- [ ] 认领 **40–60 格直线** 路径（同一条可换 Style 复测，或每条 preset 单独认领）
- [ ] 熟悉流程：**Style 选预设 → Build 计算预览 → 落地建造一小段（至少 2 基塔）**
- [ ] 开启 F3（调试屏幕）— 准星指向方块时可读 **方块 ID + BlockState**

### 每条 preset 通用步骤（约 2 分钟）

1. [ ] Style 卡片：高亮、缩略图轮廓与风格名一致  
2. [ ] Build 预览：紧凑缩略图与 Style 卡片同类  
3. [ ] 第一基塔：杆塔/塔型轮廓符合预期（木杆 / 水泥 / 格构 / 风车…）  
4. [ ] 导线：单相 **1** 根 / 三相 **3** 根（+ 地线若明显）  
5. [ ] 垂度：松垂 vs 笔直与 preset 气质一致  
6. [ ] （BlockState 项）F3 核对下表「BlockState 抽检」列  
7. [ ] 标记本行 `[x]` 通过或 `[!]` 问题（用文末模板记录）

### BlockState F3 速查

| 方块 | 合法 state 应类似 | 常见错误 |
|------|-------------------|----------|
| `lightning_rod` | `facing=east/west/north/south/up/down` | 无 facing、全部同一错误朝向 |
| `chain` | `axis=x/y/z` | 裸 `minecraft:chain` |
| `soul_lantern` / `lantern` | `hanging=true/false` | 裸 lantern、灯飘在空中无链 |
| `*_slab` | `type=bottom`（横担） | 整方块或 `type=top` |
| `vine`（柱顶） | 多面 `true`，`up=false` | 裸 vine 无垂挂 |
| `iron_trapdoor`（轮毂） | `half=bottom,open=false` + `facing` | 竖放活板门 |

**地线 / 导线为 `chain` 时**：沿线路方向应对应 `axis=x` 或 `axis=z`（水平段），不应全部为无 axis 裸链。

## 与自动化对照

| 自动化 | 游戏内本清单 |
|--------|----------------|
| `PresetMinecraftRealizabilityTest` | 全 preset 能生成、无 air fallback |
| `PresetIdentityBlockStateTest` | ⭐ 8 项 BlockState F3 |
| `PresetMinecraftRealizabilityTest` Quick Tune 矩阵 | Quick Tune 3 点 |
| `PowerLineStyleConsistencyTest` | 每 preset 风格/导线/垂度列 |
| `ConductorSpanMaterialMixBlockStateTest` | 可选 MaterialMix 段 |

**勿误判为 bug：**

- Quick Tune **杆材** 覆盖 COLUMN / 塔体主材，**不**改横担/装饰/导线默认材质。  
- **参数化 preset**（Compact Lattice、Steampunk 等）与 **catalog 设计** 顶层装饰可能不同（如 catalog 有 lantern、参数化无）。  
- ImGui 缩略图 ≠ 像素级方块一致，只验「同类风格」。
