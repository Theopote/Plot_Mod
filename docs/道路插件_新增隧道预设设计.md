# 道路插件 - 新增隧道预设设计方案

> **勘误（实施以代码与专项计划为准）**
>
> 1. 「无需修改底层代码」**仅适用于风格预设组合**，不适用于 7 种截面几何扩展。截面扩展必须先重构 `TunnelProfile` / `TunnelCrossSectionMask`（内/外轮廓），否则预览与建造不一致。
> 2. 部分文档示例照明材质（白染色玻璃、蓝冰、未通电红石灯、火把）**不会自行发光或依赖附着方向**；正式预设改用 `glowstone` / `sea_lantern` / `shroomlight` 等。
> 3. 八种风格预设应分配到不同截面（D 形 / 拱形 / 圆形 / 矩形 / 五边形 / 椭圆 / 马蹄），而不是全部落在原有三种形状上。
> 4. 「地铁」预设定位为工业管片风格，**不**承诺自动生成铁轨。

## 一、当前隧道系统架构分析

### 现有参数体系

根据 `TunnelStyle.java` 和 `ResolvedTunnelStyle.java`，隧道系统支持以下参数：

| 参数类别 | 参数名 | 取值范围 | 默认值 | 说明 |
|---------|--------|---------|--------|------|
| **形状** | `shape` | RECTANGULAR / ARCH / HORSESHOE | ARCH | 隧道截面形状 |
| **尺寸** | `clearHeight` | 3-12 方块 | 5 | 净空高度 |
| | `sideClearance` | 0-4 方块 | 1 | 侧向净空 |
| | `liningThickness` | 1-3 方块 | 1 | 衬砌厚度 |
| **材质** | `liningMaterial` | 方块ID | stone_bricks | 衬砌材质 |
| **照明** | `lightingMode` | NONE / WALL_BANDS / CEILING_BAND / WALL_AND_CEILING | NONE | 照明模式 |
| | `lightMaterial` | 方块ID | sea_lantern | 灯光材质 |
| | `lightSpacing` | 2-32 方块 | 6 | 灯带间距 |
| **装饰** | `accentRings` | boolean | false | 是否启用装饰环 |
| | `accentMaterial` | 方块ID | "" | 装饰环材质 |
| | `accentSpacing` | 2-32 方块 | 8 | 装饰环间距 |

### 现有三种预设推测

根据翻译文件，当前已有三种形状：
1. **方形（RECTANGULAR）**：传统矩形隧道
2. **拱形（ARCH）**：圆拱顶隧道
3. **马蹄形（HORSESHOE）**：底部平坦、顶部圆拱

---

## 二、新增隧道预设设计

### 设计原则

1. **功能多样性**：覆盖不同使用场景（城市、山区、地下、水下等）
2. **视觉差异化**：每种预设有明显的视觉特征
3. **性能考量**：避免过于复杂的装饰导致性能问题
4. **参数复用**：充分利用现有参数组合，无需修改底层代码

## 三、新增预设方案

### 预设 1：现代高速公路隧道（Modern Highway Tunnel）

**使用场景**：城市快速路、高速公路

**设计特征**：
- 高净空、宽敞、充足照明
- 现代感强的材质和照明
- 定期装饰环提升安全感

**参数配置**：
```json
{
  "name": "modern_highway",
  "shape": "RECTANGULAR",
  "clearHeight": 7,
  "sideClearance": 2,
  "liningThickness": 1,
  "liningMaterial": "minecraft:polished_andesite",
  "lightingMode": "WALL_AND_CEILING",
  "lightMaterial": "minecraft:glowstone",
  "lightSpacing": 4,
  "accentRings": true,
  "accentMaterial": "minecraft:yellow_concrete",
  "accentSpacing": 12
}
```

**视觉效果**：
- 灰色光滑墙面（磨制安山岩）
- 侧墙和顶部双重照明，每4方块一组
- 每12方块一个黄色警示装饰环

### 预设 2：山地古典隧道（Mountain Classic Tunnel）

**使用场景**：山区公路、景观道路

**设计特征**：
- 自然石材质感
- 拱形顶部贴合山体
- 节能照明（较稀疏）

**参数配置**：

  "lightSpacing": 8,
  "accentRings": true,
  "accentMaterial": "minecraft:chiseled_stone_bricks",

**视觉效果**：
- 粗糙圆石墙面，衬砌厚度2方块（更坚固感）
- 侧墙灯笼照明，每8方块一组（温和光线）
- 每16方块一个錾制石砖装饰环（古典风格）

2. **在UI中添加预设选择器**

在 `TunnelStyleControls.java` 或 `TunnelStyleFloatingEditor.java` 中添加：

```java
private void renderPresetSelector() {
    RoadUiSections.section("plugin.road.tunnel.preset.section");
    
    float cardWidth = (ImGui.getContentRegionAvailX() - ImGui.getStyle().getItemSpacingX()) / 2f;
    
    for (int i = 0; i < TunnelPreset.values().length; i++) {
        TunnelPreset preset = TunnelPreset.values()[i];
        
        if (i > 0 && i % 2 != 0) {
            ImGui.sameLine();
        }
        
        if (ImGui.button(
                PlotI18n.tr(preset.getTranslationKey()) + "##preset_" + preset.getId(),
                cardWidth,
                48f)) {
            applyPreset(preset);
        }
        
        if (ImGui.isItemHovered()) {
            renderPresetTooltip(preset);
        }
    }
}

private void applyPreset(TunnelPreset preset) {
    TunnelStyle presetStyle = preset.createStyle();
    currentDraft.replaceWith(presetStyle);
    ctx.status().info(PlotI18n.tr("plugin.road.tunnel.preset.applied", 
        PlotI18n.tr(preset.getTranslationKey())));
}

private void renderPresetTooltip(TunnelPreset preset) {
    TunnelStyle style = preset.createStyle();
    String tooltip = String.format(
        "%s\n形状: %s | 高度: %d | 照明: %s",
        PlotI18n.tr(preset.getTranslationKey() + ".description"),
        PlotI18n.tr("plugin.road.tunnel.shape." + style.getShape().name().toLowerCase()),
        style.getClearHeight(),
        PlotI18n.tr("plugin.road.tunnel.lighting." + style.getLightingMode().name().toLowerCase())
    );
    ImGui.setTooltip(tooltip);
}
```

## 十、总结

本设计方案提供了8种功能和风格各异的隧道预设，覆盖了从现代城市到极地环境的多种使用场景。所有预设都基于现有参数体系，**无需修改底层代码**，只需添加预设枚举类和UI选择器即可实现。

设计重点：
- ✅ **即插即用**：利用现有参数，无需架构改动
- ✅ **视觉多样**：每种预设有明显的材质和照明特征
- ✅ **场景覆盖**：从城市到山区，从水下到极地
- ✅ **易于扩展**：枚举结构便于后续添加更多预设

实施后，用户可以通过简单点击快速应用专业设计的隧道样式，大幅提升道路插件的易用性和设计效率。
