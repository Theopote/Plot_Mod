## 核心工作流程

### 基础建造流程
```
1. 打开 Plot（按 0 键）
2. 选择绘图工具
3. 在画布上绘制图形
4. 配置方块材质
5. 使用"线转方块"或直接投影
6. 预览幽灵方块
7. 确认建造
```

### 复杂项目流程
```
1. 项目规划（草图、图层划分）
2. 创建图层并命名
3. 在不同图层绘制内容
4. 使用编辑工具调整（变换、阵列等）
5. 配置各部分方块材质
6. 分步投影建造
7. 使用插件完成特殊需求（道路、地形等）
8. 在世界中检查和修正
```

### 插件使用流程（三标签结构）
```
1. 在画布绘制基础图形（路径、区域、轮廓）
2. 打开扩展面板，选择并启用插件
3. 【路径/区域标签】拾取/认领图形
4. 【编辑标签】配置参数、材质、样式
5. 【生成标签】计算预览、查看幽灵方块
6. 确认无误后投影建造
```

## 常见问题速查

### 安装与配置
**Q**: Plot 需要什么前置模组？  
**A**: Minecraft 1.21.10 + Fabric Loader (≥0.18.4) + Fabric API

**Q**: 如何打开 Plot 界面？  
**A**: 进入世界后按 `0` 键（数字键 0）

### 基础操作
**Q**: 如何切换工具？  
**A**: 点击左侧工具栏图标，或使用快捷键（如 `L` 直线、`R` 矩形）

**Q**: 绘图时如何约束方向？  
**A**: 按住 `Shift` 键启用正交约束（水平/垂直/45°）

**Q**: 如何精确对齐图形？  
**A**: 启用吸附功能（端点、中点、交点吸附）

### 方块建造
**Q**: 线转方块后高度如何设置？  
**A**: 在方块配置面板中设置高度参数（单层或多层）

**Q**: 幽灵方块预览看不清？  
**A**: 调整视角透明度，或切换到正交视图

**Q**: 如何撤销已建造的方块？  
**A**: 部分插件支持建造撤销，或手动清理后重新投影

### 插件使用
**Q**: 插件拾取模式下无法绘图？  
**A**: 拾取模式会接管画布点击，完成拾取或按 `Esc` 退出

**Q**: 道路插件如何设置交叉口？  
**A**: 在路径标签页的交叉关系中编辑

**Q**: 土方插件推荐高度不合适？  
**A**: 手动拖动目标高度滑块，实时查看预览
