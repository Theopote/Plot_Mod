## 🎯 教程概览

### 基本信息
- **教程名称**：Plot 完全教程 - 从入门到精通
- **总集数**：23 集（核心）+ 2 集（补充）
- **总时长**：约 6-7 小时
- **目标受众**：Minecraft 玩家（零基础到进阶）
- **更新频率**：每周 1-2 集

### 三大模块

#### 第一模块：基础入门（5 集）
让用户能独立完成简单建筑的 2D 规划和方块建造
- 安装与界面
- 基础绘图工具
- 编辑与变换
- 图层管理
- 方块建造

#### 第二模块：工具精通（10 集）
掌握所有绘图和编辑工具，灵活运用各种变换
- 高级绘图工具（曲线、特殊曲线）
- 高级编辑工具（阵列、修剪、倒角）
- 标注与文字
- 吸附与网格
- 综合实战（中世纪城堡）

#### 第三模块：插件与实战（7 集）
使用插件完成道路、地形整平、建筑等复杂项目
- 道路系统插件
- 土方平衡插件
- 建筑轮廓生成器
- 图案生成器
- 电力线路插件
- 终极实战（完整小镇）

## 🚀 快速开始

### 如果你是第一次参与制作：

1. **阅读顺序**：
   ```
   00-教程体系架构.md（了解全局）
   → 01-详细目录与章节内容.md（选择要制作的集数）
   → 02-制作要点与技术指南.md（学习制作方法）
   → 03-快速参考手册.md（随时查阅）
   ```

2. **准备工作**：
   - [ ] 安装录制软件（OBS Studio）
   - [ ] 配置 Minecraft + Fabric + Plot 模组
   - [ ] 准备测试世界存档
   - [ ] 设计片头/片尾模板

3. **第一集制作**：
   - 查阅 `01-详细目录与章节内容.md` 第 1 集大纲
   - 参考 `02-制作要点与技术指南.md` 录制技巧
   - 使用 `03-快速参考手册.md` 检查清单
